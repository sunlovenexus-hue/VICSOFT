# VICSOFT 

An ambitious journey into OS development, building from the boot sector up with the ultimate goal of mobile platform support.


🚀 Project Vision

VICSOFT is a custom-built operating system exploring low-level systems programming, kernels, and memory management.


🛠 Tech Stack


Languages: x86 Assembly (NASM), C (GCC)



Target Arch: x86_64



Environment: QEMU for emulation




🗺 Roadmap


 
Stage 1: Basic Boot Sector



 
Stage 2: Custom Bootloader Development



 
Stage 3: C Kernel Loading



 
Stage 4: Memory Management & Tasks





Source code for the core logic is currently private. This repository hosts the project landing page and documentation.

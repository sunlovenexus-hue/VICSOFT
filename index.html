Early stage: vision and planning

Building an operating system from zero.

VICSOFT is an independent OS project that starts at the boot sector and works up to a kernel, with the long-term goal of running on mobile devices.

The vision

VICSOFT is a learning-driven, ground-up operating system, not a Linux distribution. It begins with the fundamentals: how a CPU starts, how a kernel loads, and how memory is managed. The goal is a lean, secure system that can one day grow from the desktop to mobile platforms.

⚡

Lean by design

Hand-written assembly and small, focused C code, so every part of the system is understood.

🛡️

Memory safety first

Memory management and isolation between tasks are planned from the start, not added later.

📱

Mobile as the goal

The architecture is planned with mobile platform support as the long-term destination.

The roadmap

Stage 1: Basic boot sector

Write a 512-byte boot sector in NASM assembly that the BIOS can load and run, with simple text output.

Up next

Stage 2: Custom bootloader

Extend the boot sector into a full bootloader that loads further code from disk and prepares the CPU for a larger kernel.

Planned

Stage 3: C kernel loading

Hand control from the bootloader to a kernel written in C, and print the first messages from it.

Planned

Stage 4: Memory management and tasks

Add memory management and the ability to run and switch between tasks, the base for everything that follows, including mobile support.

Planned
